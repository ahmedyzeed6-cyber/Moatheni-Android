# مؤذني — مشروع أندرويد أولي

هوية التطبيق: كحلي ملكي + ذهبي.

## الموجود في هذا الإصدار الأولي
- واجهة عربية RTL بخمس شاشات: الرئيسية، الأذكار، القبلة، القرآن، الإعدادات.
- أوقات فلكية أولية محسوبة محليًا، تبدأ بالقاهرة كقيمة افتراضية ثم يمكن تحديثها بموقع الهاتف.
- حساب اتجاه القبلة من الإحداثيات.
- سبحة إلكترونية وأذكار مختارة.
- ربط أولي بإعدادات صلاحية عدم الإزعاج في أندرويد واختبار يدوي للوضع.

## تنبيهات مهمة قبل النشر
- هذا إصدار تأسيسي وليس تطبيقًا نهائيًا جاهزًا للنشر.
- حسابات الصلاة الحالية تقريبية وتحتاج تدقيقًا ومراجعة طرق الحساب وحدود خطوط العرض، ولا تعتمد عليها وحدها في أداء الصلاة قبل التحقق محليًا.
- الأذان الصوتي، الجدولة الدقيقة في الخلفية، واستعادة وضع الصوت السابق تلقائيًا بعد كل صلاة لم تُنفذ بعد.
- ميزة عدم الإزعاج تتطلب موافقة المستخدم. الاختبار الحالي يدوي ولا ينشئ جدولًا تلقائيًا.
- صفحة القرآن حاليًا واجهة تمهيدية، وليست مصحفًا كاملًا.

## بناء APK
ارفع محتويات هذا المجلد إلى مستودع GitHub جديد، ثم افتح Actions وشغّل `Build Moatheni APK`.
بعد نجاح البناء افتح تفاصيل العملية ونزّل Artifact باسم `Moatheni-debug-apk` ثم فك ZIP لتحصل على APK.
